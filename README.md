# e-typing 自動実行スクリプト

e-typing の「ビジネス」カテゴリにある「がんばれ新人君」をブラウザで開き、表示されたローマ字をキーボードイベントとして入力します。結果を解析し、スコアが **270–300** に入るまで入力速度を調整して再試行します。

## セットアップ

```bash
npm install
npx playwright install chromium
```

## 実行

```bash
npm start
```

デフォルトではブラウザを表示します。入力途中の画面を確認せず実行する場合は次のようにします。

```bash
HEADLESS=true npm start
```

## 設定

| 環境変数 | デフォルト | 説明 |
| --- | ---: | --- |
| `TYPE_DELAY_MS` | `200` | 文字入力間の遅延（ミリ秒） |
| `MAX_ATTEMPTS` | `5` | 目標範囲に入るまでの最大試行回数 |
| `MAKE_MISTAKE` | `true` | 最初の文章で1回だけ余分なキーを入力 |
| `HEADLESS` | `false` | `true` でブラウザを非表示 |

スコアはサイト側の出題・計時・判定に依存するため、指定範囲への到達を保証するものではありません。サイトの利用規約と公開ページの範囲内で使用してください。
